═══════════════════════════════════════════════════════════════
  CONFIGURATION
═══════════════════════════════════════════════════════════════

Vector Database Options:

  Option 1: Chroma (LOCAL - RECOMMENDED)
    VECTOR_DB=chroma
    CHROMA_URL=http://localhost:8000
    → No API keys needed
    → Offline capable
    → Perfect for development

  Option 2: Pinecone (CLOUD)
    VECTOR_DB=pinecone
    PINECONE_API_KEY=<your-key>
    PINECONE_INDEX=<your-index>
    → Scalable
    → Serverless
    → Production-ready

Switch easily: ./switch-vectorstore.sh chroma|pinecone
